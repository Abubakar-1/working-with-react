# Working with React

This project was built with **React (via Vite)** to demonstrate basic React concepts such as list rendering, conditional rendering, filtering, grouping, and component composition.

## What Was Done

- Set up a new React project using Vite
- Created 7 functional components, each addressing a different exercise requirement
- Organized all components inside **App.jsx** with clear section headings
- Styled the layout for clarity and readability
- Linked the project to a GitHub repository for submission

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/working-with-react.git
   cd working-with-react
   npm install
   npm run dev
   Open in the browser at: http://localhost:5173
   ```
